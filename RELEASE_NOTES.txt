USB mode — work on the Deluge's card without taking it out. Version 0.4.0.

Download the DelugeSampleManager-Setup .exe below and run it; it updates the version you have.
Windows may warn that the publisher is unknown: choose "More info" then "Run anyway".

New
- Card list → "Deluge over USB". The app finds the Deluge on its USB cable (Community Firmware 1.3 or
  later) and reads its card. The app remembers the choice and reconnects next time.
- Everything works over USB: browsing, Used by, the Health check, Rename / Move / Trash, Relink, the
  Factory move, Import, History and Undo.
- Moves and renames happen on the Deluge itself, so they are instant. Copying sample data runs at about
  30 KB/s (about 35 seconds per MB): the Import and Apply windows show how long, and suggest the card
  reader for big imports.
- Samples over 400 KB aren't fetched until you press Play (the waveform shows how long it would take).
- Preset and song files and sample header facts are kept on the PC after the first read, so the second
  time the card opens it is quick. Anything changed on the Deluge is read again automatically.

Only one program at a time can use the Deluge's USB ports: close the Patch Manager (or a DAW) first.
Don't use the Deluge's file browser while Apply is running.

If something goes wrong, use the Log folder button and send the dsm.log file.
