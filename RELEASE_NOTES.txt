Sample Manager. Version 0.16.1 — no more false "damaged preset" reports.

Download the SampleManager-Setup .exe below and run it; it updates the version you have.

- Fixed: the health check called 135 good presets damaged. Presets saved by Deluge firmware 1 to 3 start with
  <firmwareVersion> and <earliestCompatibleFirmware> before the <sound> or <kit>, which the Deluge reads happily but a
  strict XML check doesn't. The check now reads them the way the Deluge writes them.
- One real flaw remains: KITS/041 Jonathan Snipes (Waterfalls) is missing a </modKnobs> tag near line 1140. It came
  that way from Synthstrom (the backup taken before the sort has the same flaw), and the Deluge loads it anyway.

Sample Manager. Version 0.13.0 — tags, BPM and key, search filters and smart lists you save.

Download the SampleManager-Setup .exe below and run it; it updates the version you have.

Tags
- Type a tag in the details pane (Tags box, Enter); click a tag to take it off. Tags belong to the sound, so every
  copy has them. For many samples at once: select them, right-click › Tags….
- Tags guessed from pack and folder names (a pack called "Psychill …" → psychill) show grey with a "?". Click one to
  confirm it or take it off, or right-click a pack under SOURCES › Confirm guessed tags. Guesses don't count in
  searches until confirmed. The words that make guesses are in Settings › Tag words….
- A Tags column in the list.

BPM and key
- BPM and Key columns, and boxes in the details pane. They come from what you type, then the file's own tempo
  (its acid chunk), then the file or folder name (145bpm, Bass Loop 145 F#m, Key of D). Flats are shown as
  sharps: Gbm is F#m. Clear a box to go back to the guess.
- A file's own tempo is read when it is added to the library or first played. Library ▾ › Read tempos from loop
  files… reads it for all your loops at once.

Search
- Filters: type:kick  type:hat  loop  -loop  tag:dark  bpm:140-150  key:F#m  len:<1s  on:syntakt  -on:any
  src:paid  pack:"dark mass"  dupe  wontplay  untagged. All words must match; a minus turns one round.
  The ? button beside the search box lists them.
- The search works in the list you're looking at; select LIBRARY to search everything.
- Save as smart list… keeps a search under SMART LISTS, with a count. Right-click it to rename, change or delete it.
- Your tags, typed BPM/key and smart lists are saved in the library's _Sample Manager folder (tags.json,
  smart-lists.json), so they're kept on Drive.

Sample Manager. Version 0.12.0 — the Syntakt.

Download the SampleManager-Setup .exe below and run it; it updates the version you have.
Windows may warn that the publisher is unknown: choose "More info" then "Run anyway".

The Syntakt
- With the Syntakt connected by USB, TARGETS › SYNTAKT lists its 64 sample slots by type, with each sample's ID
  when it is in the library. Click one to hear it: it is read from the Syntakt once, then from the PC.
- The Twin Shot check compares the Syntakt with Factory › Syntakt in the library (by name and length — the
  Syntakt keeps its samples at 48 kHz, so the audio itself differs): "Twin Shot pack complete", or what differs.
  Right-click SYNTAKT › Twin Shot check… for the details.
- A Syntakt column in the list shows the slot of every library sample that is on the Syntakt.
- Send: right-click library samples › Send to the Syntakt… puts converted copies (48 kHz 16-bit mono, names cut
  to 16 characters) into EMPTY slots. Factory samples, and samples the app didn't put there, are never replaced,
  because every project using a sample would change. Your Syntakt's 64 slots are all in use, so for now there is
  no room — that is expected.
- Remove (only samples the app put there), Undo the last Syntakt change, Back up all its samples to
  Backups › Syntakt, and Get from Syntakt (samples that aren't in the library, into User) are on the right-click
  menus. Every change saves the slot first and reads the result back. Restart the Syntakt to use changed samples.
- The Syntakt is looked for at start and on Refresh. Close the Patch Manager, Overbridge and Elektron Transfer
  first: only one program can use its USB MIDI at a time.

Fixed
- A background job could finish without the window hearing about it, so a sample could stay on "Loading…".

Sample Manager. Version 0.10.0 — duplicates.

Download the SampleManager-Setup .exe below and run it; it updates the version you have.
Windows may warn that the publisher is unknown: choose "More info" then "Run anyway".

A duplicate is the same audio in more than one file: the same sound data, whatever the file is called and
whatever else is in its header.

- SMART LISTS › Duplicates in the library: every sound that is in the library more than once, with each copy
  listed (the details pane shows where the other copies are). The library itself is never changed.
- ON THE DELUGE › Duplicates on card: reads the card (only files whose length and format match another file's
  are read in full, so it is quick) and shows each sound with its copies and how many kits, synths and songs
  use each one.
  - The copy marked "keep" is a factory copy if there is one, else the one used most. Right-click another
    copy to keep that one instead, or untick a sound to leave it alone.
  - Tidy the card points every kit, synth and song at the kept copy and moves the other copies to the card
    trash, through the pending tray as usual: nothing changes until you press Apply, and History can undo it.
  - Factory samples, and the Deluge's own recordings and clips (CLIPS, RECORD, RESAMPLE, EXPORTS), are never
    moved; they show as "stays".
  - A library sample that was linked to a removed copy is linked to the kept copy instead.
