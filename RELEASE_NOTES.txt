Updates itself. Version 0.8.1.

Download the DelugeSampleManager-Setup .exe below and run it; it updates the version you have.
Windows may warn that the publisher is unknown: choose "More info" then "Run anyway".

- The Sample Manager now checks GitHub for a new version. When there is one it asks: Update now, Later or
  Skip this version. Update now downloads the installer, closes the app, installs quietly and starts the
  new version. (The GitHub repository must be public for this to work.)
- Help ▾ › Update settings… chooses how often it checks: at start and every 6 hours (the default), at start
  only, or only when you ask. Help ▾ › Check for updates… checks straight away.
- Nothing is checked or downloaded while a dialog is open; the question waits until it closes.

Samples by type. Version 0.8.0.

Download the DelugeSampleManager-Setup .exe below and run it; it updates the version you have.
Windows may warn that the publisher is unknown: choose "More info" then "Run anyway".

New
- BY TYPE in the left pane, with counts: Drums → Kick, Snare, Clap, Closed hat, Open hat, Cymbal, Tom,
  Percussion, Other drums; then Bass, Synth, Keys, Pad, Vocal, FX, Instrument, and Unknown.
- The type is the app's best guess from the file name, or failing that the nearest folder name
  (".../Kicks/Bright 01.wav" is a Kick). Hats that don't say open or closed are judged by length:
  short = closed, long = open; the rest show as "Hats, open or closed?".
- A Type column next to Name, and a Type line in the details pane saying where the guess came from.
- Show: One-shots and loops / One-shots only / Loops only, under the list. It works on every list,
  and the BY TYPE counts follow it.
- Right-click one or many library samples → Set type… to correct the guess. Your choice always wins,
  survives rescans, and "Go back to the app's guess" undoes it. Nothing is written to the sample files.
- The first start after updating works out the types of the whole library (a few seconds).

Fix: the app froze when moving between big lists. Version 0.7.1.

Download the DelugeSampleManager-Setup .exe below and run it; it updates the version you have.
Windows may warn that the publisher is unknown: choose "More info" then "Run anyway".

Fixed
- Clicking a big list (Paid, All, a large vendor) after another big list froze the window, so the sample
  seemed stuck on "Loading…". Switching lists now takes a couple of seconds even with 20,000 samples.
- Working out which samples are on the card is much quicker for big lists.
- If a sample takes more than a few seconds to load, the app now says so (for example while Google Drive
  downloads it) instead of sitting on "Loading…". You can pick another sample at any time.

Library-first layout, like the Patch Manager. Version 0.7.0.

Download the DelugeSampleManager-Setup .exe below and run it; it updates the version you have.
Windows may warn that the publisher is unknown: choose "More info" then "Run anyway".

New
- The left pane now shows the samples on the PC first:
    LIBRARY (count) → 🔒 Factory / Free / Paid → vendor → pack, each with how many samples it holds.
    SMART LISTS → On the card, Not on the card, Won't play on the Deluge.
    ON THE DELUGE → the card's own folders, at the bottom, for recordings, clips and Health check work.
- Clicking a vendor or pack lists every sample in it at once (not one folder level). Columns: Name, Pack,
  Origin, On card, Length, kHz/bit, Used, Deluge. Samples on the card are bold green with a ✓.
- The library is indexed into a small database on the PC, so it opens instantly. "Scan library"
  (Ctrl+R) picks up new or changed files; it also runs by itself at start-up and after imports.
- Right-click a pack, vendor, Free or Paid: "Send N not yet on the card to the card…".
  Right-click library samples: "Send to the card…" or "Remove from the card…" (to the card trash; samples
  a kit, synth or song uses stay).
- The details panel shows which kits, synths and songs use a library sample's copy on the card.
- Search now searches the whole library ('unused' still lists unused samples on the card).

The first scan reads every sample's header once. If the Samples folder in Google Drive is set to
stream, set it to "Available offline" first, or the first scan downloads each file.

If something goes wrong, use the Log folder button and send the dsm.log file.
