Milestone M4 — rename, move, relink and the factory move. Version 0.3.0.

Download the DelugeSampleManager-Setup .exe below and run it; it updates the version you have.
Windows may warn that the publisher is unknown: choose "More info" then "Run anyway".

New
- Right-click samples on the card: Rename…, Move to another folder…, or Move unused to the card trash.
- Right-click a card folder under SAMPLES: Rename folder…, Move folder into….
- Every kit, synth and song that uses a moved or renamed sample is updated to the new path. Only the
  path text inside each preset changes; every other byte stays exactly as the Deluge wrote it.
- Health check, Missing samples: "Relink to this match" (when the card has one file of that name) or
  "Relink to a file…" points the presets at the right file.
- Factory move… (toolbar, and in the Health check's Folder layout section) moves the factory folders
  under SAMPLES/FACTORY. You see the list of folders first and can untick any that are yours.
- Apply shows every file that moves and every preset line that changes (− old, + new) before anything
  is written. It backs up first, including a copy of every preset and song that changes, and checks
  afterwards that every rewritten path points at a real file.
- History → Undo puts everything back. A preset you have saved again on the Deluge since is left alone
  and reported, never overwritten.
- Nothing is ever deleted: trashed samples go to DSM_TRASH at the card root.

If something goes wrong, use the Log folder button and send the dsm.log file.
